# Game Pet Agent Demo

这是一个独立于 NPC 主项目的本地可运行 Demo，用于验证：

- 屏幕截图 -> 硅基流动 VLM 决策 -> 键鼠执行
- 可编辑角色 Prompt
- 明确的运行状态标记（运行中/已停止/已急停/异常）

## 功能（当前 Demo）

- **双界面**：配置页 + 开始后收成一行控制条（开始/暂停/设置/日志）
- **独立日志窗口**：记录 AI 请求/响应、解析动作、错误详情；同时写入 `logs/session_*.log`
- **错误遮罩**：异常时在控制条下方显示半透明黑底报错区（含 HTTP 状态码与响应正文）
- 桌面窗口控制：开始、停止、紧急停止（Esc）
- 全局急停热键（默认 `Ctrl+Alt+S`，窗口失焦也可触发）
- 目标窗口保护：仅在指定游戏窗口激活时执行输入
- 状态灯：绿色运行中，灰色已停止，橙色急停/异常
- 支持输入：
  - API Key
  - 模型名
  - 系统 Prompt（角色设定）
  - 当前任务 Prompt（例如“你现在是模仿玩家，完成这个游戏测试”）
- 循环执行：截图 + 请求 `/v1/chat/completions` + 解析 JSON 动作序列 + 逐步执行
- **结构化输出**：`thinking`（思考过程，仅记录不执行）+ `final.steps`（最终可执行操作）
- **原生多步**：`final.steps` 可含多步（如先点界面 → 点对话框 → 按键），最多 12 步，步间约 0.35s
- 动作白名单：`wait` / `click` / `key` / `type` / `stop`（仍兼容旧版单步 `action` 格式）

## 快速开始

1. 安装 Python 3.10+
2. 安装依赖

```bash
pip install -r requirements.txt
```

3. 运行

```bash
python src/main.py
```

## 硅基流动 API 说明

- 端点：`https://api.siliconflow.cn/v1/chat/completions`
- 认证：`Authorization: Bearer <YOUR_KEY>`
- 视觉输入：使用 `image_url` + `data:image/jpeg;base64,...`（OpenAI 兼容格式）

## 使用建议

- 视觉模型较慢时，建议“循环间隔”≥ 180 秒（3 分钟），避免上一步 API 未结束就进入下一步；可在 30~600 秒范围内按需调整。
- 请在测试环境运行，不要直接在生产账号上使用自动输入。
- 若模型动作不稳定，优先在系统 Prompt 中加强“只返回 JSON + 不确定时 wait”约束。

## 已知限制

- 当前是单代理 Demo，尚未包含复杂状态机与卡死恢复策略。
- Esc 为应用级紧急停止（窗口失焦时不保证全局热键能力）。
- 全局热键依赖系统键盘监听权限，个别环境可能被安全策略拦截。
- 不同游戏 UI 差异较大，建议按游戏场景迭代 Prompt 和动作规则。
